Миний тухай

Шинжлэх ухаан, технологийн их сургуулийн Мэдээлэл, холбооны технологийн сургуулийн Мэдээллийн технологийн чиглэлээр 2-р курсэд суралцдаг. Программчлал болон веб хөгжүүлэлтийн чиглэлээр мэдлэг, ур чадвараа хөгжүүлэн суралцаж байна.

Би шинэ зүйл сурах, асуудлыг программчлалын аргаар шийдвэрлэх болон өөрийн санааг веб хуудас, программ хэлбэрээр хэрэгжүүлэх сонирхолтой. Цаашид веб хөгжүүлэлт болон тоглоом хөгжүүлэлтийн чиглэлээр илүү гүнзгий мэдлэг эзэмших зорилготой.

Эзэмшсэн чадварууд

  • HTML5 & CSS3 үндэс
  • Git & GitHub хувилбар удирдлага
  • Программчлалын C++ хэл
  • Python программчлалын хэл
  • Алгоритм болон логик сэтгэлгээ
  • Программ хөгжүүлэлтийн үндсэн ойлголтууд
  • VS Code ашиглан код бичих
  • Аливаа байгууллагийн үйл ажиллагаанаас асуудал олж харж шийдэл олох

Веб хөгжүүлэлтийн мэдлэг

HTML ашиглан веб хуудасны үндсэн бүтэц үүсгэх, гарчиг, догол мөр, жагсаалт, холбоос болон бусад HTML элементүүдийг ашиглах чадвартай. CSS ашиглан веб хуудасны харагдах байдал, байрлал болон дизайныг хөгжүүлэх чиглэлээр суралцаж байна.

Хийж буй болон хэрэгжүүлсэн төслүүд

  • Миний CV веб хуудас – HTML ашиглан өөрийн танилцуулга болон чадваруудыг харуулсан веб хуудас.
  • Программчлалын хичээлийн төслүүд – C++ болон Python хэл ашиглан төрөл бүрийн алгоритм, программын бодлогуудыг хэрэгжүүлсэн.
  • GitHub төсөл – Git болон GitHub ашиглан кодоо хадгалах, хувилбар удирдах болон repository-той ажиллаж байна.

Миний зорилго

Ирээдүйд чадварлаг программист болж, веб болон тоглоом хөгжүүлэлтийн чиглэлээр мэргэшихийг хүсдэг. Мөн бодит төсөл дээр ажиллаж, багийн ажиллагаа болон программ хангамж хөгжүүлэх туршлага хуримтлуулах зорилготой.
